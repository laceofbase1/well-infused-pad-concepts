Well Infused · Functional Fusion Protocol

Three ways to make a pad that is not a menu.

Every pathway has to be pre-printed, which makes the sheet structurally a list of all seven. So the whole design problem is making a pre-printed list read as a determination that was already made rather than a set of options on offer. Each concept answers that differently. Both states are shown: the blank pad as it comes off the press, and the same sheet after a visit.

01

Order of Care

The authority of a real clinical order.

Borrows the credibility of a lab requisition: tight caps labels, a ruled field structure, and a plain-language descriptor under every pathway so the patient can read it again at home. The Foundation sits in a full-bleed blue band with its two green dots already filled at press time, so the sheet arrives with the foundation prescribed before the NP writes a word. Green ink appears nowhere else on the page, which means a green dot can only ever mean prescribed.

  • Most information per page, and the only concept that explains each pathway to the patient.
  • Reads as a medical order. That is the point, but it is also the least warm of the three.
  • Safest choice if a copy goes in the chart.
02

The Spine

The protocol drawn as a structure, not a list.

A blue spine runs down from the Foundation block and terminates in the reassessment date. Each pathway is a node on that spine, and the ones the NP fills are the ones drawing from the foundation. This is the hub-and-foundation graphic solved typographically, so choosing it also seeds the interactive version later. Didot returns on exactly two words, which is the use the brand guide specifies.

  • The only concept that makes the clinical model visible as a shape.
  • Most patient-facing of the three. Reads like a personal document rather than a form.
  • Least room for detail: no pathway descriptions, and the fewest fields.
03

Standing Order

No checkbox anywhere on the sheet.

There is nothing to tick, because nothing was chosen. A pathway becomes prescribed when the NP writes into it, and an empty tinted slot reads as deliberately blank rather than unticked. Pathway names are set large but recessive, so from across a kitchen you see only the filled blocks. The Foundation is a charcoal slab with no fields at all, and the single saturated moment on the page is the green return-date band.

  • Strongest answer to the menu problem, because the menu affordance is simply gone.
  • Best as a fridge document. Still legible at four feet.
  • Asks the NP to write in every prescribed row, with no quick tick.
  • Heaviest ink coverage, so the highest print cost.

Before this gets built out

Four things worth deciding once, rather than three times.

  • Dana's existing pad is much bigger than this brief. It also carries a supplement formulary of roughly 34 named products across eight categories, a pharmacy and peptide list, membership and package pricing, and a Next Appointments block. None of that is in these three concepts, because the handoff did not mention it. Whichever concept wins will need a second page or a reverse side to hold it, and that is a structural decision, not a styling one.
  • Pricing on a clinical order. The old pad puts dollar figures next to memberships and packages on the same sheet as the prescription. If the new model is a clinical determination rather than a menu, price probably belongs on a separate sheet. Worth confirming before the layout is locked.
  • Naming collision. "Functional Fusion" is already live on wellinfused.com as a specific lab-driven IV protocol, the 3-Series and 6-Series. Here it is also the name of the entire framework, and the IV Therapy row is exactly where an NP would write "FF 6-Series." The collision shows up on a single sheet. This needs either the site or the framework renamed, and I have not quietly resolved it.
  • Logo files. The wave mark here was rebuilt as clean vector from the brand PDF, so it is sharp at any size, but the wordmark is set in live Avenir rather than the original artwork. Request the vector files from the brand owner before a print run.
