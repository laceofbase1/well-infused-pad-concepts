# Well Infused — Functional Fusion Protocol, prescription pad concepts

Four design directions for the Functional Fusion Protocol prescription pad, each shown blank
(as it comes off the press) and filled in (after a visit).

**View: https://laceofbase1.github.io/well-infused-pad-concepts/**

| File | What it is |
|---|---|
| `index.html` | All four concepts on one page, with notes and open questions |
| `concept-01-order-of-care.html` | Print-ready, US Letter |
| `concept-02-the-spine.html` | Print-ready, US Letter |
| `concept-03-standing-order.html` | Print-ready, US Letter |
| `concept-04-the-spine-clinical.html` | Print-ready, US Letter |

Set in Avenir and Didot per the Well Infused brand guide, with web fallbacks so the pages render
correctly on any machine. The wave mark is true vector, rebuilt from the brand PDF.

Concepts only. Nothing here is final artwork, and the logo wordmark is set in live type rather than
the original vector files.
