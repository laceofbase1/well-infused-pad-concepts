# Well Infused — Functional Fusion Protocol

The selected prescription pad, in two options, plus the four-page clinical formulary behind it.

**View: https://laceofbase1.github.io/well-infused-pad-concepts/**

## Selected direction

**Order of Care**, the clinical-order layout, with the return date in a light wash of the brand
green (`#E7EEDA`, a tint of Pantone 376C). Two options, identical apart from the Notes block:

| File | What it is |
|---|---|
| `index.html` | Everything on one page, each sheet shown blank and filled in |
| `pad-option-a-original.html` | **Option A.** Original layout. Pathway rows at 38pt. |
| `pad-option-b-notes.html` | **Option B.** Adds two ruled Notes lines. Rows compress to 33pt. |
| `formulary.html` | **The formulary.** 4 pages, 111 entries, 11 open placeholders. |

All sheets are US Letter and print at exact size.

## The formulary

Supplements lead the document, because they are the foundation.

1. **The Foundation** — 34 supplements in 8 categories, from the current pad
2. **Hormones and peptides** — pharmacy Rx split out from peptides
3. **Infusions and procedures** — 10 named infusions, 4 lab-driven protocols, injections, ozone,
   salt room, regenerative medicine
4. **Memberships, packages, open items** — pricing as it appears on the current pad, plus explicit
   placeholders for everything not yet supplied

IV, peptide, ozone and regenerative lists were pulled from wellinfused.com rather than the project
handoff, which was incomplete. Peptides went from 2 named compounds to 13.

Anything not yet supplied renders as a dashed placeholder row rather than being omitted.

## Notes

Set in Avenir and Didot per the brand guide, with Nunito Sans and Bodoni Moda as web fallbacks so
the pages render correctly off a Mac. The wave mark is true vector, rebuilt from the brand PDF; the
wordmark is set in live type, so request the original vector files before any print run.

Concepts and working drafts. Nothing here is final artwork.
